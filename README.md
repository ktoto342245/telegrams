# Telegram Bot

Це простий Telegram-бот, написаний на Python з використанням бібліотеки `pyTelegramBotAPI`.

## Інструкція:

1. Встанови залежності:
```
pip install pyTelegramBotAPI
```

2. Замініть `YOUR_BOT_TOKEN_HERE` у `bot.py` на ваш токен від BotFather.

3. Запусти бота:
```
python bot.py
```
